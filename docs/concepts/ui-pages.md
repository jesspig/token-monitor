# UI 页面规划

> [!note] 当前状态
> 规划阶段，页面为设计清单，尚无组件实现。

## 页面清单

| 页面 | 内容 |
|---|---|
| Dashboard | Hero 汇总卡 + 时间范围筛选（今日 / 7 天 / 30 天） |
| 趋势 | 请求趋势折线 + Token 趋势（输入/输出/缓存创建/缓存命中/成本） |
| 请求日志 | 分页表格 + 筛选（应用/模型/时间/状态）+ 行详情 |
| 统计 | 按应用 / 按模型的聚合表 |
| 定价配置 | 模型价格列表 + 增删改 |
| 监控源 | 各 CLI 适配器状态（已检测/未安装/最近同步时间/错误数） |
| 设置 | 同步间隔、数据保留策略、数据目录等 |

## 交互要点

- Hero 卡由筛选驱动，切换范围/应用/模型时同步更新。
- 趋势粒度：今日按小时（24 点），7/30 天按天。
- 「监控源」页展示各监控插件状态（已检测/未安装/最近同步时间/错误数），支持启停插件。
