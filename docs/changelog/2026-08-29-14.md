## 趋势合并与查询性能收敛

### 动机

- 趋势页双图与仪表盘分属两份 `range`/`filters` 与重复查询，切换时重复建 `queryKey`（含秒级 `Date.now()` 抖动）与多图动画叠加致感知卡顿（见 2026-08-28-21/22/23 遗留）。
- `getDailyModelBreakdown` 固定 30 天按 `date,model` 再聚合，此前直查 `usage_records` 全表扫描，未利用 `usage_daily_rollups` 预聚合；`queryClient` 轻池单点串行加剧瀑布。
- 统计页 `tokenStack/costStack` 用 `filter` 每日期二次扫描为 `O(n²)`。

### 变更

- **仪表盘合并**：`src/renderer/src/pages/DashboardPage.tsx` 移除简图 `TrendChart`，内联原 `TrendsPage` 的 `buildHourlyRows/buildDailyRows` 与双卡（卡 1 请求 `LineChart` + 卡 2 Token 四桶 `Area` 堆叠 `stackId tokens` + 成本虚线右轴），按 `range` 自动切 `today/24h→hourly` 其余→daily；`src/renderer/src/App.tsx` 移除 `TrendsPage`/`TrendingUp` 及 `trends` 导航，`NAV_ITEMS: 7→6`，`PAGES` 对应移除；`App.tsx` 切页改为 `visitedRef:Set<PageKey>` 常驻渲染+`display:none` 切换，已访问页不卸载重建。
- **导航契约**：`src/renderer/src/context/NavContext.tsx` `PageKey` 移除 `trends`（`'dashboard'|'logs'|'stats'|'pricing'|'sources'|'settings'`）；`src/renderer/src/pages/RequestLogsPage.tsx` 详情抽屉 `nav.navigate('trends')` 改 `dashboard`，按钮文案同步为“在仪表盘查看”。
- **查询预聚合**：`src/main/services/usageQuery.ts:queryDailyModelRows` 接入预聚合快路径——`canUseRollups(filters)` 为真时改查 `usage_daily_rollups`（`buildRollupWhere` + `GROUP BY date, model`，`SUM(tokens/cost/request_count)`）否则回退 `usage_records`（`strftime` + `GROUP BY date, model`）；主路径命中时仪表盘双图不再触及明细表。
- **索引**：`src/main/services/db.ts` 新增 `MIGRATIONS v11` `CREATE INDEX IF NOT EXISTS idx_usage_records_model_created ON usage_records(model, created_at)`，兜底带维度过滤的回退明细路径（`model + created_at` 范围过滤）；`user_version: 10→11`。
- **Worker 分流**：`src/main/worker/queryClient.ts` `HEAVY_METHODS` 纳入 `getDailyModelBreakdown`（`getStatsByProject/Session/Status` + `getRequestLogs`/`getUsageSummary`/`getDailyModelBreakdown` → `pool[0]`，其余轻查询 → `pool[1]`），错开统计页与仪表盘的瀑布。
- **前端缓存与渲染**：`src/renderer/src/lib/range.ts` `rangeToFilters` 的 `now/startTime/endTime` 均按分钟对齐 `Math.floor(Date.now()/60_000)*60_000` 以稳定 `queryKey`；`src/renderer/src/hooks/useUsageSummary.ts`/`useRequestLogs.ts`/`useDailyTrends.ts` 与 `DashboardPage` 内联 `hourly/budget` 统一 `staleTime 2min + gcTime 30min + placeholderData: keepPreviousData`；`src/renderer/src/components/TrendChart.tsx`、`TrendsPage.tsx`、`StatsPage.tsx`、`DashboardPage.tsx` 双图全量 `isAnimationActive={false}` 去动画抖动；统计页 `src/renderer/src/pages/StatsPage.tsx` 的 `tokenStack/costStack` 由 `filter` 每日期二次扫描改为 `Map<date, Map<model,value>>` 一次遍历。
- **测试**：`src/main/services/db.test.ts`、`storage.test.ts`、`pricing-source.test.ts` 同步 `user_version` 断言 `10→11`，并对新索引存在性做校验。
