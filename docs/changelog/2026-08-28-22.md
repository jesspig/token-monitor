# 2026-08-28 趋势与统计 UI 二次打磨（对标 OpenCode DATA 四图，上下排布）

> 按小时合并记录。本条目为 2026-08-28-21 多维迭代后的二次打磨，重点修复用户反馈的白屏、卡顿、响应式与图表价值问题。

## 背景（用户反馈截图）
- 趋势页白屏：请求/Token 两个卡片仅有 X 轴与虚线网格，无线条；仪表盘底部趋势仅一条竖线。
- 硬性能差：切换维度/时间档明显卡顿。
- 统计页响应式差：`lg:grid-cols-2` 并排使表格 `min-w-[760px]` 与饼图相互挤压，饼图 10+ 切片标签重叠不可读。
- 图表数据未拆分：Dashboard 6 序列共图导致请求数被 Token 碾压；饼图单一费用占比价值低。
- 表格列过多（8 列）需拆分；建议增加柱状图；图表希望上下排布利于响应式。

## 对标 OpenCode DATA（https://opencode.ai/zh/data）
- 市场份额：按日堆叠柱状（多提供方分段）+ 底部图例网格（01 DeepSeek 4.8T 21.7% 等）
- 独立用户：同为按日堆叠柱状（不同分布，橙色主导）
- 热门模型：Top 18 卡片网格（01-03 大卡 + 其后 4 列小卡，rank/模型/归属/Token/请求/费用/成功率）
- Weekly Retention：横向点状条排行（rank/model/ retention 轴/ RATE / ELIGIBLE）

## 本轮改动

### 趋势 / 仪表盘（白屏与拆分）
- **DimensionChart**：`DimensionSeries.stackId` 支持，Bar/Area 均透传 `stackId`；YAxis 显式 `domain=['auto','auto']` 双轴独立；`isAnimationActive={false}` 保留。
- **TrendsPage**：白屏根因 `Number.parseFloat(undefined)`→NaN 与 Token/请求共轴挤压；修复 `buildHourlyRows/buildDailyRows` 全字段 `||0` 兜底，`domain auto` 独立；拆为 **三卡上下排布**——卡1 请求单线 200px，卡2 Token 堆叠（bar/area 切换，stackId tokens 四色），卡3 成本柱状 200px；Range 切换改 `useTransition` + `keepPreviousData` + `staleTime 2min` 消除闪烁；`filterDaily` mock 改为 `filterRecords` 后聚合以尊重 appTypes/models 过滤。
- **DashboardPage**：原单图六序列拆为 **两卡上下排布**——卡1 请求单线，卡2 内上下堆叠 Token 堆叠柱状 + 成本柱状独立；`trendChartData` 全字段 `||0` 且 cost 转 number；`tokenView` 柱状/面积切换；`min-h-[180px]` 保初绘高度。
- **useDailyTrends**：加 `staleTime 2min` + `keepPreviousData`。

### 统计页（响应式、列拆分、图表价值）
- **DimensionTable**：外层 `grid-cols-2` 并排改为 `space-y-6` 上下堆叠（表格全宽在上，图表全宽在下）；`min-w` 760→640；维度 tabs 下新增 `MetricView` 二级 tabs（概览 / Tokens 明细 / 全部）按视图条件渲染列，合计行同步；Top7+Others（>8 时前7 + Others）+ 横向条形 `layout="vertical"` 动态高度已在上一轮落地，本轮保留并默认 `chartType='bar'`（价值高于饼图）。
- **ShareChart**：饼改环形（inner 45% outer 70% paddingAngle 2），`label={({percent})=> percent>0.08? pct% : ''}` + `labelLine={false}` 消除重叠，依赖 Legend/Tooltip；柱状改横向 `layout="vertical"`，`YAxis width 110` 截断 14 字符，`barSize 16`，高度 `max(260, n*34+32)`。
- **新增 LeaderboardGrid.tsx**：热门 Top 18 卡片网格（与 OpenCode 一致：首行 3 大卡 `md:grid-cols-3`，其余 `sm:grid-cols-2 lg:grid-cols-4`），每卡 rank/模型/归属/Token总量/请求/费用/成功率徽章，`memo`。
- **新增 RetentionRanking.tsx**：Weekly Retention 风格横向点状条排行（RANK/MODEL/RETENTION 轴/RATE/ELIGIBLE），`rate*100%` 处白色竖线标记，`useMemo` 排序，`memo`。
- **StatsPage**：重写为上下排布的四图 + 表格：`RangeSelector` → `LeaderboardGrid`（Top 18）→ `Token 市场份额` 堆叠柱状（`stackedTokenSeries`）→ `每日请求` 堆叠（`stackedRequestSeries` success/error）→ `RetentionRanking` → `DimensionTable`（详细表），每段为独立 `Card` 全宽；`isPending` 过渡 `opacity-60`，`useTransition` 切档。
- **性能**：`useDimensionStats` 加 `staleTime 2min` + `keepPreviousData` + `gcTime 30min`；`DimensionTable` 维度/指标切换改 `startTransition`，`sorted`/`totals`/`shareData` 均为 `useMemo`，`chartType` 默认 `bar`。
