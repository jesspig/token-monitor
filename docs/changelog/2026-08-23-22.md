## 变更二：三个新插件

- **plugins/pi.ts**：sessions 子树递归收集 `.jsonl`；header 状态机取 sessionId/cwd；`type==='message'` 且 assistant+usage 产出；semantics=2；requestId=条目 id（fork 跨文件收敛）。
- **plugins/zcode.ts**：opencode 同构 SQLite 模式——只读打开 + WAL mtime max + **rowid 水位游标**（line=rowid 单调唯一）；LEFT JOIN session 取 directory；semantics=1（input 含缓存由计费侧扣减）；reasoning 不加速率；createdAt=completed_at ?? started_at。
- **plugins/dsh.ts**：`.jsonl.zstd` 经 **fzstd（纯 JS zstd 解压，零 native 依赖，规避 Electron ABI 坑）** 整文件解压后逐行解析 envelope；`type==='assistant/message'` 且 data.usage 产出；semantics=2；requestId=`<sessionId>:<seq>`；SQLite 后端工件暂不支持（detect reason 提示）。
- host.ts BUILTIN_PLUGINS 登记至 8 个；src/main/index.ts 注释同步。
