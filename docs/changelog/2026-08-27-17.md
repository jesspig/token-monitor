## 小时物化 + worker 线程 offload + 系统托盘常驻（文档同步）

> 本轮为 docs/ 知识库概念页同步修订，如实反映已实现的三项变更：小时粒度物化（v10）、统计查询 offload 到只读 worker 线程、系统托盘后台常驻。仅文档，不执行编译/单测（依要求）。

### 背景（已核实实现）

1. **小时粒度物化（v10）**：`src/main/services/db.ts` 新增迁移 v10，建 `usage_hourly_rollups`（主键 `(date, hour, app_type, model)`，含 request_count/success_count/error_count/各 token/cost_usd/latency_ms_total/updated_at），并在 `storage.recordUsage` 入库**同事务**增量维护（与日聚合镜像同口径累桶）；`usageQuery.queryHourlyRows` 无筛选维度时读该表（带 status/project/sessionId/keyword 时回退 `usage_records` 全扫）；迁移含一次性回填与三单列索引（`idx_usage_records_status` / `idx_usage_records_project` / `idx_usage_records_session_id`）及小时表 `idx_usage_hourly_rollups_date`；`createDatabase` 已启用 WAL。`PRAGMA user_version` 幂等升级，回放安全。
2. **统计读取 worker 线程 offload**：新增 `src/main/workers/query-worker.ts`（只读 `better-sqlite3` 连接，`{ readonly: true, fileMustExist: true }`，WAL 下读已提交快照）与 `src/main/worker/queryClient.ts`（主线程 RPC 客户端，相同 `(method+args)` 并发请求 in-flight 去重收敛 `usage-updated` 失效风暴）；`host.usageQuery` 改为 `QueryClient`；`:memory:` 时回退进程内直查；`before-quit` 调 `terminate()`。
3. **后台常驻（系统托盘）**：新增 `src/main/tray.ts`（`createTray`），`index.ts` 关窗拦截→隐藏到托盘、`window-all-closed` 常驻不退出、单实例锁、`before-quit` 清理；`AppSettings.closeToTray` 默认 `true`；设置页新增开关。
