## 主进程防阻塞第二轮（消除「每步操作未响应」的正反馈闭环）

### 代码改动

1. **外部 SQLite 只读连接短超时**：opencode.ts / zcode.ts 新增常量 `EXTERNAL_DB_BUSY_TIMEOUT_MS = 250` 并传入 `new Database(path, { readonly: true, timeout: ... })`——better-sqlite3 撞锁时在主线程同步忙等，默认 5000ms 会冻结整个应用；现撞锁约 250ms 即放弃本轮采集（返回空结果），由下轮兜底重试。
2. **回填/存量重算分批执行**：pricing.ts 的 backfillZeroCost / recalcCachedInputCosts 重构为 rowid 游标按 `REPRICE_BATCH_SIZE = 500` 逐批扫描，每批「事务外取价计算 → 单事务原子提交」，批间 setImmediate 让出事件循环；两函数候选查询分别命中 v7 部分索引 idx_usage_records_zero_cost / idx_usage_records_cached_input，稳态扫描成本从 O(全表) 降为 O(候选数)。
3. **schema v6→v7**：db.ts 新增 v7 迁移，创建上述两个部分索引——`idx_usage_records_zero_cost ON usage_records (cost_usd) WHERE cost_usd IS NULL OR cost_usd = '0'`；`idx_usage_records_cached_input ON usage_records (input_semantics) WHERE input_semantics = 1 AND app_type IN ('codex', 'gemini', 'grok')`。WHERE 与各自候选查询条件完全一致；CREATE INDEX IF NOT EXISTS 保证 user_version 回拨重放安全。
4. **调度错相**：SchedulerService.schedule 增加可选第三参 `initialDelayMs`（首触到点立即执行一次再进周期；缺省 = intervalMs，与原 setInterval 语义一致）；host.ts 过期清理调度经 `RETENTION_SWEEP_PHASE_OFFSET_RATIO = 0.5` 错相半个周期点火，启动先行一次的 `RETENTION_SWEEP_DELAY_MS` 由 30s 上调至 45s，错开 30s 处的存量费用重算。
5. **状态查询与探测短路**：collector.getPluginStatus 增加 5s TTL 缓存（`STATUS_CACHE_TTL_MS = 5000`）+ `invalidateStatusCache()`，plugins:set-enabled IPC 处理后主动失效；pi/dsh 插件 detect 从整树递归 listFilesFromRoot 改为 hasSessionFile 存在性短路递归（找到首个会话文件即返回，不做逐文件 stat）；grok loadModelMap 增加 summary.json 清单「path:mtime 签名」短路，清单未变化时复用上次映射、跳过全部重读重析。

## 渲染端刷新收窄与交互修复

### 代码改动

8. **全局轮询移除**：main.tsx 移除 QueryClient 全局默认 refetchInterval；仅用量类查询（useUsageSummary / useDailyTrends / useStats×2 / useRequestLogs + Dashboard 内联 hourly 与 budget-status + Trends 内联 hourly，共 8 处）显式 `refetchInterval: getStatsRefreshInterval`——设置项「统计自动刷新间隔」语义随之收窄为仅控制用量类图表轮询；settings/plugins/pricing/filter-options 不再轮询，依赖挂载刷新与操作后 invalidate（SourcesPage/PricingPage/SettingsPage 已有手动 invalidate）。
9. **事件失效改防抖**：useUsageEvents 由节流改防抖——INVALIDATE_COOLDOWN_MS(1000) → INVALIDATE_DEBOUNCE_MS(1500)，CLI 活跃期事件流安静 1.5s 后合并失效一次，不再每秒一轮全量重取。
10. **日志页搜索与翻页体验**：RequestLogsPage 关键字搜索 300ms 防抖（新 hook useDebouncedValue，查询值与输入值分离，发布后回第 1 页）；useRequestLogs 加 `placeholderData: keepPreviousData`，消除翻页/筛选切换时表格闪空。
11. **设置页首载守卫**：SettingsPage 表单回填仅首载一次（hydratedRef 守卫），不再被数据刷新覆盖编辑中输入。
