## 当前代码事实

### 宿主与数据库

- 内置插件总数保持 31。
- `host.ts` 通过 `createBuiltinPlugins(getTraeTrajectoryRoots)` 工厂装配插件；Trae 使用 `createTraeAgentPlugin` 并显式注入设置 getter，不再是静态 `BUILTIN_PLUGINS` 常量。
- SQLite schema 升至 v14。
- `UsageRecord` 增加可选 `isReplaceableSnapshot`。
- `usage_records` 增加：
  - `request_id TEXT`
  - `is_replaceable_snapshot INTEGER NOT NULL DEFAULT 0`
- 新增同源非空 requestId 唯一部分索引 `idx_usage_records_data_source_request_id`。
- v14 迁移不改写旧行：旧行 requestId 为 NULL、快照标记为 0。

### 可替换成功快照

只有新旧记录满足以下条件时才更新现有明细：

- 相同 `data_source + request_id`。
- 新旧 `is_replaceable_snapshot=1`。
- 新旧 `status='success'`。

有效更新保留原内部主键，刷新业务字段、证据位置和时间，并在同一事务中从明细重建受影响的旧/新日桶、小时桶；空桶删除。完全相同快照返回 0，有效替换返回 1；事务任一步失败整体回滚。

当前逐源启用：

- Claude：成功且有 `message.id`。
- Kiro current SQLite：当前库的稳定 turn 快照；旧 sidecar 不启用。
- Droid：成功且有 `message.id` 的 JSONL usage；settings 不产出记录。

错误、无稳定 ID 和其他插件继续使用不可变 first-write-wins。

### 插件兼容性更新

- DSH：支持 legacy `session.jsonl[.zstd]` 与 `session.v1/v2.jsonl[.zstd]`；重启时重放已消费前缀恢复 session/model；未来版本、未知压缩、`.dsh` 和 SQLite 后端显式不兼容。
- Kilo Code：支持 current `kilo.db` 和旧扩展 `ui_messages.json`；当前库采用只读 SQLite、WAL mtime、rowid 水位和 `message.id`；当前库 input/cache 关系未知，semantics=0，旧扩展保持 2。
- Kiro：支持 current `data.sqlite3/conversations_v2` 和旧 JSONL+sidecar；当前库 mtime 变化后重读并通过可替换快照收敛；没有显式 input/output Token 时拒绝估算，缓存为 0，semantics=0。
- Copilot CLI：从游标前缀重建每模型、每 Token 桶历史高水位；内存缓存仅优化性能；累计回退不产生负数。
- gptme：递归发现 `branches`；只使用顶层或 metadata 中明确稳定消息 ID 做跨文件身份，缺 ID 不用内容哈希猜测。
- Trae Agent：设置页配置多个 trajectory 根，配置优先于 `TRAE_TRAJECTORY_DIR` 和旧默认候选；路径在主进程校验，watcher 动态刷新，不扫描用户目录或磁盘。
- Command Code：每次解析文件前缀以恢复 session/project/model/parentMap/活动尾节点；前缀不产出。
- CodeWhale：保守快照；首次不回填历史，总量增长取差值，下降/compaction 重置，fork 新文件首次只建基线；不拆分未知 output/cache。
- OpenCode/DevEco/MiMo：共享内核改为数据库指纹 + rowid 编码水位；旧时间戳游标、数据库身份变化或 rowid 回退从头重读；保留相同身份/rowid 的历史行原位更新仍不重产。
- Cline/Roo：覆盖 VS Code Stable、VS Code Insiders、VSCodium、Cursor；稳定身份优先 requestId、文本 requestId、时间戳，最后才退回数组索引。Cline CLI/SDK-managed 会话未接入。
- MiniMax：只有 session_id、turn_id、记录 id 均有效时才生成 `minimax:[session,turn,id]` 语义身份，处理 legacy/runtime 双库重叠。
- Droid：JSONL 快照跨轮收敛；settings 文件仅做发现、mtime 和 JSON/schema 验证，不计 Token、不从费用反推。
