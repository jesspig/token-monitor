# 2026-08-28 统计页六项精修与趋势回退修复

## 用户反馈的 6 项问题

1. **热门 Top 18 → Top 10**：按使用量（Token 总量）取前十。
2. **每日 Token 堆叠**：标题改为“每日 Token 消耗量”，应为堆叠柱状但空白；表格参考 OpenCode 热门板块，悬停看各模型，多柱拼合。
3. **详细维度表**：出现全 0 模型（如 `<synthetic>` 3 请求 0 Token）不合理，应过滤。
4. **费用占比**：只取前 5，含第 6 起归 Others；应为堆叠柱状（单条 100% 堆叠）而非横条，参考市场份额。
5. **成功率排行**：增加“缓存命中率排行”。
6. **新增**：绘画成本排行（每绘画平均成本）与每百万 Token 消耗量（分输入/输出/缓存）。
