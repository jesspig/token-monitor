# 2026-09-10 00:00

## 图表层 ECharts 迁移 + UI/UX 状态反馈与信息架构系统化

### 动机

- 渲染层图表库 Recharts 体积大（862KB 级）、声明式组件树在 `visitedRef` 常驻渲染场景下更新成本高，且样式在各页散落重复（StatsPage `PALETTE` 与 ShareChart `DEFAULT_PALETTE` 两份色板定义）。
- 六页数据区加载/错误/空态表现不一致：存在「加载中…」EmptyState 冒充加载态、「等待真实数据」等开发视角文案；写操作（保存/启停/同步）结果以内联文字呈现，缺乏统一反馈。
- 时间范围筛选在 Dashboard/统计/日志三页各持 local state，切页不保持，且统计页无法使用自定义区间。
- 表格数值列左对齐不可比、排序控件无障碍缺失、日志抽屉无 Escape/焦点管理。

### 变更

- **图表层整体迁移 Recharts → ECharts 6.1**：依赖新增 `echarts ^6.1.0`（按需引入 `echarts/core` + Line/Bar/Pie + Grid/Tooltip/Legend/DataZoom/Title + CanvasRenderer），recharts 卸载；`electron.vite.config.ts` manualChunks 改 `echarts|zrender → 'echarts'` chunk，原 charts（recharts/d3）分组移除。新基建：
  - `hooks/useECharts.ts`——实例生命周期（init / `setOption(replaceMerge:'series')` / ResizeObserver resize / dispose），容器 0 尺寸容错，`display:none` 常驻页切换回来自动补 init/resize。
  - `components/chart-theme.ts`——`CHART_PALETTE` 10 色统一色板（收敛原 StatsPage/ShareChart 两份重复定义）、TOOLTIP/AXIS/LEGEND/GRID 暗色样式常量、`buildBaseOption()` 暗色骨架工厂（浅合并、整字段覆盖）、`registerECharts()` 幂等按需注册。
  - DashboardPage：双图迁移（请求趋势 Line + Token 四桶堆叠面积渐变 + 成本虚线右轴 `yAxisIndex:1`）；图例点击显隐走 ECharts 内置；tooltip `trigger:'axis'` + 系列级 valueFormatter（`formatTokens`/`formatUsd`）；Y 轴统一 `formatCompact`（修复请求趋势轴原始数字直出的旧缺陷）。
  - StatsPage：每日 Token/每日费用堆叠柱（stack + 末序列 `borderRadius [4,4,0,0]`）、费用占比 donut（`radius 45%/70%` + `padAngle 2` + 中心 title 显示区间总费用 + label 仅 >8% 显示）、tooltip axis + 自定 formatter、Y 轴 `formatCompact`/`formatUsd`；数据聚合算法（tokenStack/costStack Map 一次遍历）逐字未动。
- **状态与反馈系统化**：新基建 `components/QueryState.tsx`（四态边界：首载错误→整页错误卡+重试 / isPending→骨架 cards/chart/table 三变体 / 空→EmptyState 可传 action CTA / 正常+轮询失败→amber 提示条 `role=alert`+重试；`dimWhenRefreshing` 刷新降透明，正确处理 keepPreviousData 的 isPending+placeholder 组合）、`context/ToastContext.tsx` + `components/Toast.tsx`（success/error 两型、2800ms、上限 4 条、右下角 z-50）、`hooks/useDismissable.ts`（Escape capture 关闭 + Tab 焦点圈 + 开/关焦点移入归还）、`components/Toggle.tsx`（`role=switch`）。六页全部接入 QueryState 四态；「加载中…」EmptyState 冒充加载态的用法全部移除；开发视角文案改用户视角（EmptyState 默认文案「暂无数据」、App.tsx Mock 徽标「演示数据模式」）。分页动作：SettingsPage 保存 try/catch + toast 成功/失败 + 保存按钮 pending、托盘 checkbox→Toggle；SourcesPage 启停按钮 pending/disabled + toast + 空态引导；PricingPage 新增客户端模型搜索框（过滤后分页、回首页）、同步结果改 toast（移除内联文字行）；RequestLogsPage 的 DetailDrawer/ModelFilter 接入 Escape+焦点圈+滚动锁、空结果空态带「清除筛选」CTA（重置全部筛选回第 1 页）。
- **表格**：DimensionTable 数值列全部 text-right + tabular-nums（TH/TD 拆 text/num 两套）；排序 th 改 button + `aria-sort` + ▲▼ aria-hidden + sr-only 升/降序文本；行下钻 tabIndex + Enter/Space 键盘可达；默认渲染 50 行 + 「显示全部 N 行」展开（排序/切维度/切视图重置）；合计行算法零改动。RequestLogsPage 数值列右对齐 + 模型列 `max-w-[180px]` truncate。
- **信息架构**：时间范围全局化——FilterContext 既有 `range/customRange` API（默认 7d）激活为唯一来源，Dashboard/统计/日志三页 local state 删除、切页保持，RangeSelector 统一置于 PageHeader action 插槽（统计页因此获得自定义区间能力），Logs 页默认 30d→7d。StatsPage 布局 9 卡重组——Top10+费用 donut 两列（`xl:grid-cols-2`）、每日 Token/维度表/每日费用堆叠单列全宽、成功率/缓存命中/会话成本/每百万 4 紧凑卡两列（`xl:items-start`），断点 xl≥1280px 避开历史回归区间。
- **设计 token**：`tailwind.config.cjs` theme.extend 新增语义色（surface/card/raised、line/line-strong、content/content-secondary/content-muted、success/warning/danger/info 各 DEFAULT 400 档 + bright 500 档，映射自 neutral/emerald/amber/red/sky）；`index.css` 追加全局 `:focus-visible`（emerald 描边）、`@keyframes sk-shimmer` + `.sk-shimmer`、`prefers-reduced-motion` 降级；`lib/format.ts` 新增 `formatCompact(n)`（B/M/k 缩写，非有限值 '—'），既有导出零改动。
