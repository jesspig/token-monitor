### 主进程吞吐（D1/D2/D3a/D3b）

- `services/usageQuery.ts`：新增 `prepareCached(db, sql)` 语句级预编译缓存（`WeakMap<db 实例, Map<SQL 文本, Statement>>`）；动态 WHERE 语句按最终 SQL 文本 memoize（组合有界，防炸缓存）。
- `plugins/dsh.ts` zstd 尾部帧级增量解压：`scanZstdFrames(buf, from)` 快路径整段交 fzstd decompress（内建多帧循环，对帧内容伪 magic 免疫）；失败（典型 = EOF 半帧正在写入）时从尾部倒序探测 magic 候选作为安全切割点 cut 前缀解压——cut 为真帧边界必成功、为伪 magic 则真帧截断必失败被自然排除；候选耗尽 → ok:false（真损坏，游标不动）。parseFile 续读（fromLine>1 且游标 byteOffset 为合法帧边界）仅解压新增帧，片段首行全局行号 = fromLine；偏移非法/中途坏帧回退整块解压自愈并回填偏移；EOF 半帧只推进到最后完整帧末尾；增量空文本短路（line 不虚进、byteOffset 照推）。会话头 LRU 缓存衔接逻辑不变。
- schema v6 迁移（`services/db.ts`）：`sync_cursors` 增可空列 `byte_offset INTEGER`（ALTER 前 table_info 列存在性守卫，schema 级幂等，兼容 user_version 回拨重放）；`services/storage.ts` 的 `setCursor(filePath, line, fileMtime?, byteOffset?)` / `getCursorMeta` 支持 byteOffset——缺省保留现值、显式传入（含 null）覆盖、truncate 重置双清；line_offset/byte_offset upsert 单语句实现（@keep_byte_offset/@reset_cursor 控制位）；truncate 判定收紧：existing.file_mtime=0（插件占位）不参与判定。
- `services/pricing.ts`：定价索引升级 `PricingIndex{map, keys(字典序数组)}`（缓存重建时排序）；`shortIdPrefix` 从长到短枚举 id 真前缀 + lowerBound 二分判存在；家族兜底 lowerBound 连续段扫描（最短优先同长字典序规则不变）；短 ID/家族匹配 O(n·L) → O(L·log n)；五级匹配语义与顺序逐字保留（点转横线精确仍先于一切前缀模糊）；calcCost 改委托抽出的 computeCost（行为零变化）；新增 `calcCostBatch(records)`（单次取索引后 map computeCost，按位对应、无价 undefined、空数组短路、异常向上抛；shared/context.ts PricingService 接口同步新增）。
- `collector.syncOne` 计费循环由逐条 `await calcCost` 改为一次 `calcCostBatch` + 按位回填 costUsd（undefined 跳过），异常仍由单文件 try/catch 兜底。
