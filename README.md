# Token Monitor

一款桌面端小工具，帮你统一管理本机上多个 AI 编程助手的 **Token 用量与花费**。

它不需要你配置任何代理，也不会上传你的数据——它只在本地读取各个 AI 编程工具的会话记录，自动汇总成清晰的图表和报表，让你一眼看清「今天花了多少、哪个工具最费、哪个模型最贵」。

---

## 它能帮你做什么

- **一处看全**：同时监控多个 AI 编程工具，不用再逐个打开各自的面板对账。
- **花多少一目了然**：按时间、按应用、按模型统计 Token 与费用，趋势图直观呈现。
- **预算提醒**：设置每日 / 每月预算，临近或超出时横幅自动变色提醒。
- **明细可追溯**：每一次请求的 Token 明细都可查看，方便核对与排查。
- **价格自动更新**：内置主流模型价格，并会自动从源头同步最新定价，无需手动维护。

## 快速上手

### 1. 安装与启动

从发布页面下载对应系统的安装包（Windows 为 `.exe` 安装程序，macOS 为 `.dmg`，Linux 为 `.AppImage`），双击安装后启动即可。

> 首次启动后，工具会在后台自动扫描本机已安装工具的会话记录并开始统计，你无需做任何配置。

### 2. 查看总览

启动后默认进入 **Dashboard（总览）** 页面，这里展示：

- 当前所选时间范围内的 **总 Token、总费用** 等关键数字；
- 顶部 **预算横幅**：设置了预算后，占比 ≥ 80% 显示黄色警告，超出显示红色；
- 请求量与 Token / 费用的 **趋势双图**：今天与最近 24 小时按小时展示，其余范围按天；
- 通过页面上的时间范围筛选，可切换「今天 / 最近 24 小时 / 7 天 / 14 天 / 30 天」，或自定义起止日期。

### 3. 看懂各页面

左侧固定导航栏可切换以下页面：

| 页面 | 用途 |
|---|---|
| **总览 Dashboard** | 核心数字汇总 + 预算横幅 + 时间范围筛选 + 请求 / Token / 费用趋势双图 |
| **请求日志 Request Logs** | 每一次请求的明细表格，支持按应用、模型、项目、时间、状态筛选，也能关键字搜索；点击任意一行可看详情 |
| **统计 Stats** | 按模型 / 应用 / 项目 / 会话 / 状态五个维度聚合，帮你找出最费 Token / 最贵的部分 |
| **定价 Pricing** | 各模型价格只读列表，可一键「立即全量同步」刷新最新价格 |
| **监控源 Sources** | 查看每个被监控工具的状态：是否已发现、CLI 版本、最近同步时间、是否有错误；也可在此启停某个工具的监控 |
| **设置 Settings** | 调整同步频率、数据保留时长、每日 / 每月预算、自动刷新间隔等 |

## 常用功能说明

### 切换时间范围

在总览、统计、日志页面顶部都能选择时间范围（三者共享同一时间范围）：

- **今天**：从本地今天 0 点到现在；
- **最近 24 小时**：滚动的 24 小时窗口；
- **7 天 / 14 天 / 30 天**：按天回溯；
- **自定义**：点「自定义」打开日期面板，选好起止日期后应用即可。

### 设置预算提醒

进入 **设置** 页面，填写「每日预算」和 / 或「每月预算」（留空表示不启用）。设置后：

- 总览页顶部的预算横幅会根据今日 / 本月已花费占比变色；
- 临近（≥ 80%）变黄，超出变红，方便你及时控制使用。

### 查看某次请求明细

在 **请求日志** 页面：

- 用顶部筛选器按应用、模型、项目缩小范围；
- 输入关键字搜索（支持模型名、项目名等）；
- 点击任意一行，展开查看该次请求的完整信息，包括 Token 拆分与状态。

### 找出最费的部分

在 **统计** 页面：

- 切到「按应用」看哪个工具最耗；
- 切到「按模型」看哪个模型最贵；
- 还可按「项目 / 会话 / 状态」查看更细的维度；
- 回到 **总览** 结合趋势图，判断是用量在涨还是单价偏高。

### 价格与同步

- 模型价格默认随工具自动从源头同步，一般无需干预；
- 若想立即刷新到最新定价，进入 **定价** 页面点「立即全量同步」即可；
- 价格列表为只读，确保计费口径一致、可复现。

### 启停某个工具的监控

在 **监控源** 页面，每个工具都有开关。如果某个工具你暂时不想统计，关掉即可；想恢复时再打开，数据会接着之前的继续累积。

## 数据说明

- **完全本地**：所有会话记录都在你自己的电脑上读取与计算，不上传任何数据。
- **自动累计**：工具在后台持续监听各工具的会话文件变化，新的用量会自动计入，无需手动刷新。
- **缓存与重复处理**：对于流式输出、会话分支（fork / 压缩）等会产生重复记录的情况，工具会自动去重，避免费用被重复计算而虚高。
- **失败请求可见**：请求出错（如接口报错）也会记录并单独标记，便于你发现异常，但用户主动中断（取消 / 打断）的操作不会被计为错误。

## 小贴士

- 刚启动或刚装好某个 AI 工具时，稍等片刻，数据会在后台自动补齐。
- 想对账某段时间，用「自定义」时间范围最方便。
- 预算横幅是最简单的「省钱开关」：设一个你能接受的上限，超了就看得见。
- 不同工具的会话文件格式会随版本变化，本工具已做宽松兼容，一般不会因升级而中断统计。
